1. **Red:** escreve um teste que descreve o comportamento esperado.
2. **Green:** escreve o mínimo de código para o teste passar.
3. **Refactor:** melhora o código, com o teste garantindo que nada quebrou.
   
   
SDD (Spec-Driven Development)
Aqui existe uma ambiguidade, e vale saber os dois sentidos:

- **Sentido mais recente:** escrever uma **especificação** (requisitos, comportamento esperado, critérios de aceite, tarefas) **antes** de implementar, e usar essa spec como guia do desenvolvimento. Ficou popular com o uso de IA no desenvolvimento, onde a spec é o que orienta a geração de código.
- **Sentido clássico, parecido:** desenvolvimento guiado por contrato, como definir a API em OpenAPI/Swagger antes de codar, para front e back combinarem.
